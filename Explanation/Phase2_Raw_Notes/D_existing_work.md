## D2. Epic documentation and staff statements

- **Iris Prioritization** (page header "Unreal Engine 5.9 Documentation", labelled **Experimental**), https://dev.epicgames.com/documentation/en-us/unreal-engine/iris-prioritization-in-unreal-engine:
  - "Replication priority accumulates across network ticks until an object is replicated and its priority is reset."
  - Below 1.0 an object is not considered that frame; 1.0 and above it is, if it has changed properties.
  - Built-ins: Sphere, SphereWithOwnerBoost, NetObjectCountLimiter. The page's sphere defaults (InnerRadius 1000, OuterRadius 5000) **differ from 5.8.4's source** (2000 / 10000, `SphereNetObjectPrioritizer.h:19–35`).
  - A custom prioritiser implements `UNetObjectPrioritizer` and is registered with `+NetObjectPrioritizerDefinitions=(PrioritizerName=..., ClassName=/Script/<Module>.<Class>, ConfigClassName=/Script/<Module>.<ConfigClass>)`; objects use it through `GetPrioritizerHandle` + `SetPrioritizer`.
- **Actor Priority** (legacy), https://dev.epicgames.com/documentation/en-us/unreal-engine/actor-priority-in-unreal-engine: "You can customize actor priority by overriding the virtual function GetNetPriority"; "The only thing that matters with priorities is their ratio"; "Use caution when overriding an actor's GetNetPriority."
- **Iris bandwidth** (forum, Epic staff Alex Koumandarakis, 2025-10-15), https://forums.unrealengine.com/t/how-is-server-to-client-bandwidth-controlled-in-iris-in-ue-5-5/2675046: "Currently, Iris uses the same configurable bandwidth limits as the default replication system"; mentions `net.Iris.PacketSequenceSafetyMargin` (default 4) and `net.Iris.ReplicationWriterMaxAllowedPacketsIfNotHugeObject` (default 3). (His summary of which side uses `ConfiguredInternetSpeed` vs `MaxClientRate` reads the other way round from the code; the code in `World.cpp:7471` is what we follow.)
- **Migrate to Iris / Introduction to Iris / Replication Graph** docs and the 5.7 Iris strategy post are summarised in [research/03](../Research/03_existing_solutions_gap_analysis.md) §4. Epic, Jan 2026: "no plans to deprecate the legacy replication system or the Replication Graph".
- **Unreal Fest Orlando 2025, "Developing and Launching a New Replication System"**: covers Replication Graph → Iris migration, filtering and prioritisation. Video only; not watched ([research/02](../Research/02_technical_challenges.md) [T3-D]).
